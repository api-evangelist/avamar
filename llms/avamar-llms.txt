# Avamar

> Avamar is enterprise backup and recovery software built on client-side global data deduplication. Founded in Irvine, California and backed by Lightspeed Venture Partners, it was acquired by EMC in November 2006 for approximately $165 million and now ships as Dell Avamar within the Dell Technologies data protection portfolio. Avamar is customer-hosted — deployed as an appliance, a Data Store grid, or a virtual edition — so its REST API runs on the customer's own server rather than on a Dell-operated multi-tenant host.

## Key facts

- Deployment: customer-hosted (on-premise appliance / virtual edition). There is no public API host and no free-tier signup.
- Current product release: 19.12.
- API base path: `https://<AvamarServer>/api/v1`, where `<AvamarServer>` is the IP address or FQDN of the customer's own Avamar server.
- Machine-readable API description: a Swagger UI served from the appliance at `https://<AvamarServer>/api/swagger-ui.html`. Dell does not publish a downloadable OpenAPI document.
- Authentication: OAuth 2.0. Register a client with `POST /api/v1/oauth2/clients` using HTTP Basic admin credentials, then obtain a bearer access token with `POST /api/oauth/token` (grant_type=password). Access tokens are RS256 JWTs with a default 1800-second lifetime; refresh tokens default to 43200 seconds.
- Scopes: `read`, `write`, `all` (auto-approve), plus the OIDC `openid` and `profile` scopes for Avamar Web UI single sign-on. Effective permissions also depend on the Avamar role and domain bound to the token.
- Long-running operations are asynchronous: they return a `task` resource polled through QUEUED, RUNNING, then SUCCESS, ERROR, CANCELED or ABORTED.
- No idempotency-key contract, no documented pagination parameters, no rate-limit headers, and no RFC 9457 problem+json errors. Errors return an HTTP status plus a `message` element; activity failures carry numeric Avamar event codes.
- First-party command line: `mccli` (Management Console CLI), plus `avtar`, `avmaint`, `avmgr`, `dpnctl` and `avinstaller`. No Avamar client library is published to npm, PyPI, Maven Central, NuGet, RubyGems, Packagist or crates.io.
